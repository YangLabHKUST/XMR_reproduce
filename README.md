# XMR reproduction code

Simulation and real-data analyses for Figures 3–7 of the XMR paper, organized by the
experimental categories in Figure 2. The XMR method is provided in
[YangLabHKUST/XMR](https://github.com/YangLabHKUST/XMR).

## Workflow

1. Install the [software dependencies](environment/README.md).
2. Obtain GWAS from [GWAS_data_sources.csv](https://github.com/YangLabHKUST/XMR/blob/main/GWAS_data_sources.csv),
   follow the [formatting notes](FORMATTING.md), and place formatted GWAS, LD scores and
   LD reference panels at the locations in [DATA.md](DATA.md). Trait metadata are included.
3. Run the analysis entry point for an experiment. It estimates the required backgrounds,
   selects instruments, fits the methods and writes result tables.
4. Run the separate plotting command from that experiment's README.

The real-data workflows start from formatted summary statistics with study-specific QC
already applied. Background parameters are generated by the analysis workflow; they are
intermediate outputs, not prerequisite data downloads. XMR and comparison methods use their
own background settings, as documented for each experiment.

Run the examples from the repository root. The real-data entry points also locate the
repository when launched from another directory. Each real-data folder has `code/run_analysis.R`
to run all analysis steps, and individual method scripts for running a single method.
`run_analysis.R --help` lists the steps without running them.

Result tables and intermediate backgrounds are written under each analysis folder's `results/`;
real-data figures are written under its `figures/`. Plotting can read existing results directly.
Use a fresh results directory when changing input data, model settings or package versions,
since some method scripts reuse existing backgrounds or completed fits.

Real-data analysis and plotting use R. Simulation input generation and LD processing use
Python, with Bash connecting the stages. Notebooks are not required.

GWAS, LD resources and result tables are supplied separately. The final Figure 3 composition
script is pending; the included evaluation scripts produce general simulation summaries.
